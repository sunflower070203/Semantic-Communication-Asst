# Q5: 什么是任务导向通信（task-oriented communication）？和经典通信范式有什么不同？

- 状态: OK | 用时: 92s | 时间: 2026-08-23 21:33:20 中国标准时间
- 召回来源: 2201.01389.pdf(0.59), 2206.02596.pdf(0.24), 2212.01485.pdf(0.49), 2401.13387.pdf(0.50)

## 回答

任务导向通信（Task-Oriented Communication）是语义通信的核心范式之一【I】。其根本宗旨是将完成收发双方的协同任务作为通信的终极目标【II】，在相关学术界定中常直接等同于任务/目标导向通信（对应Level 2与Level 3通信）【III】。

与经典通信（技术通信）范式相比，其主要差异体现在：
1. **优化目标**：经典通信致力于降低符号或比特传输错误率，追求物理层的精确重建；任务导向通信则聚焦于准确提取与解释符号背后的语义，旨在缩小收发端间的语义差距，而非单纯追求比特无误【V】。
2. **系统架构**：经典通信遵循“信源编码-信道编码-信道传输-信道解码-信源解码”的线性流程；任务导向通信引入了语义编解码与同义映射等扩展模块，接收端在解析语义后可直接触发与任务相关的动作（Take Action）【IV】。
3. **评估指标**：传统系统依赖误码率（BER）或误符号率；任务导向系统采用与具体业务强相关的指标（如任务执行准确率、决策成功率等）进行性能度量【I】。
4. **应用定位**：经典通信适用于通用数据传输；任务导向通信专为智能体协同场景设计，广泛应用于机器对机器（M2M）或人对机器（H2M）的自主交互与决策【V】。
